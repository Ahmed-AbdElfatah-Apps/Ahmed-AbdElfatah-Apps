# 🎓 MR. Ahmed Abd-ElFatah Academy — Unified Student Portal

A secure, high-performance web portal and database synchronization system built for student workspace management. This portal features an **OS-level installation enforcer (Lock Screen)**, floating anti-screen recording tracking watermarks, real-time database queries, and a custom **Archive.org secure proxy streaming pipeline** built on Cloudflare Pages and Edge Workers.
